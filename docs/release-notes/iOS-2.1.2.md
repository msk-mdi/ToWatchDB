## What's new
- Settings is easier to use on iPhone: Save, Test, and Remove each have their own row instead of squeezing onto one, and Language and Where to Watch Country open a list.
- Settings shows the app's version at the bottom.
- When a Seerr address over plain http is blocked, for example a name like server.lan, Seerr now explains why and suggests an address that works: the short name, the server's IP address, or https.
